# パーソナル情報ハブ＆デイリーコンシェルジュ 設計・実装計画書

インタビューを通じて明確になった要件と、既存のObsidian Vault（`やるメモ.md` や `趣味ガチャ.md` 等）の運用スタイルを踏まえた全体設計と実装計画です。

---

## 1. コンセプト：「余計なことを考える手間を減らし、今の自分を明瞭にする」

1. **ノイズのない差分確認（Inbox Zero型SNSチェック）**
   - YouTube / Pixiv / X 等を直接開いてタイムラインやおすすめ欄に時間を奪われるのを防ぎ、**「指定したアカウント・作品タグ・URLの前回からの差分（未読分）だけ」**をアプリ内で完結して確認・既読化できる。
2. **ラフな記述から「今日なにする？」を自動構造化（Obsidian完全統合）**
   - `やるメモ.md` に短文で雑に書き留める自由さはそのまま維持し、AIが裏で「朝ルーチン」「今日やること（Must）」「帰ったら・やりたいこと（Want）」「アイデア・記録」に整理。Googleカレンダーの予定・天気・空き時間と掛け合わせて**「今日やること＆AIからの具体的な行動提案」**をパッと見やすく提示する。
3. **「今の私」の可視化と有益な発見（AIキュレーション）**
   - Vault全体（進行中の制作、勉強中の技術、予算感、趣味）から「今の自分のプロファイル」を抽出し、それに合わせた**AI技術ニュース解説・お得情報（Steamセールや近場の安いスポット等）・面白い読み物記事**を毎日届ける。

---

## 2. システムアーキテクチャ

PCがスリープしていてもスマホ（Androidネイティブアプリ）からいつでも快適に閲覧・操作でき、かつXやPixiv・ローカルのObsidianファイルとも安全に連携できる**ハイブリッド構成**を採用します。

- **フロントエンド**:
  - **Flutter マルチプラットフォームアプリ** (`flutter_app/`): Androidネイティブアプリ、Windowsデスクトップ、Webに対応。
  - **軽量Webダッシュボード** (`backend/static/`): Flutter SDKが入っていない環境（学校PCなど）でもPythonサーバーを起動するだけで即座にブラウザで全機能を操作可能。
- **クラウドハブ**:
  - **Supabase (PostgreSQL + Realtime)**: 外出先・PCスリープ時でもスマホと同期可能。未設定時はローカルSQLite/JSONへ自動フォールバック。
- **PC常駐バックグラウンドワーカー (`backend/`)**:
  - **Obsidian双方向ウォッチャー**: `やるメモ.md` / `趣味ガチャ` / Vault解析と即時書き戻し。
  - **SNS・カスタムURL収集エンジン**: YouTube / Pixiv / X / RSS / 任意Webサイトの差分検知。
  - **AIコンシェルジュ (Gemini API)**: ラフメモ構造化、今日の提案、URLからの抽出ルール生成、AIニュース解説・お得情報・良記事キュレーション。

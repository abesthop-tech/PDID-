# Obsidian Vault 双方向同期＆コンシェルジュ整理スキル (`obsidian-sync`)

Obsidian Vault内のノートを読み書き・同期する際は、以下の仕様と安全基準を守ってください。

## 対象ノートと役割

1. **`01_Inbox/やるメモ.md`（メインのデイリーハブ）**
   - **朝ルーチン**: ファイル上部の `- [ ] お神体に一礼1拍手` 等のチェックボックス群。
   - **今・今日・帰ったら**: `***今とか今日とか...***` や `***帰ったら***` セクション配下のタスク・メモ。
   - **明日・休日・休暇**: `***明日やるための記録...***` や `***休み中にやりたいこと***` 配下の計画。
   - **やりたいかもリスト**: `***やりたいかもだけどやらなくてもいいやつ***` 配下の項目やリンク。
   - **同期ルール**: アプリ側でタスクの完了（チェック）や新規メモ追記が行われた場合、該当セクションの行のみを正確に更新し、他のコールアウト（`> [!NOTE]` や `> [!info]` 等）やDataviewブロックを決して破損させないこと。

2. **趣味ガチャ連携（`01_Inbox/趣味ガチャ.md` 互換）**
   - **プール元ファイル**:
     - `GAME`: `01_Inbox/したいゲーム.md` (`- [[タイトル]]` 形式)
     - `STORY`: `01_Inbox/見たい物語.md` (`- [[タイトル]]` 形式)
     - `SINGLE`: `01_Inbox/単発 やりたいリスト.md` (`- 項目` 形式)
   - **進行中ファイル**: `01_Inbox/いまやってる・見てるもの.md`
   - **ログファイル**: `01_Inbox/趣味ガチャ_log.md` (`- YYYY-MM-DD [カテゴリ] [アクション] タイトル`)
   - **試食ルール**: 「1話 / 1章 / 30分だけ試す」を完了条件とし、「よかった」なら元リストから削除して `いまやってる・見てるもの.md` へ移動、「もう興味ない」なら元リストから削除して `趣味ガチャ_log.md` へ記録する。

3. **「今の私」プロファイル抽出**
   - `01_Inbox/10月26日までに完成させる.md`、`01_Inbox/MOC *.md`、`30_Journal/日記/*.md` 等の最近更新されたノートから、現在の関心事・予算制約・進行中プロジェクトを要約し、ダッシュボードの提案精度を高める。
